One satirical sentence roasting lawmakers who would regulate AI, crypto or the
internet but cannot convert a file to PDF.

## The entry

> The senator regulating AI is himself a corrupted .docx: six years chairing the tech committee and nobody has managed to convert him into a readable PDF.

**152 characters** (limit: 320). One sentence.

## How to run

```sh
python3 main.py
# writes the entry to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output/entry.txt)
```

Python 3.13, standard library only. No network, no dependencies.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
python3 -S main.py   # also works with no site-packages
```

## Why it fits the brief

The field is saturated with committee-meeting and "couldn't convert the PDF"
jokes, so this line takes a fresh angle: it flips the premise and makes the
lawmaker himself the broken file. A senator who chairs the tech committee yet
cannot be converted into a readable PDF is the regulation debate in one image —
he wants to govern the machines while being, himself, an unreadable format.
The twist lands in the second half ("nobody has managed to convert *him*"),
which is where the bytes are spent; the setup is one concrete object
(a corrupted .docx) with no explanation.
